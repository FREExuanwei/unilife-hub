# 第六阶段：学习记录、统计与专注计时

依据用户的第六阶段完整需求，直接在现有项目实施，本地开发和测试，保留全部前五阶段功能。不部署，不开发第七阶段。

## 数据与时间

学习领域独立拆分类型、校验、统计、持久化解析和计时状态机；沿用原 shared snapshot 的一次原子写入。统一版本升为 5，新增 studyRecords 与 pomodoro（子版本 1）。旧版本 1–4 保留原字段并初始化空学习记录和 25/5 分钟设置。这样专注完成与学习记录在同一次 localStorage 写入提交，避免写了一半、重复记录或删除关联丢失历史。

记录包含要求的字段、独立 date、可空起止时间、课程名称快照。时长统一整数分钟，1–1440。直接时长记录无虚构精确起止时间；时间段记录使用本地日期和时间构造 timestamp，结束须晚于开始。手动记录只接受已经发生的学习，不能填写未来日期/结束时间。番茄钟保存实际活跃时间段，暂停时间不计入。跨午夜的计时按活跃时间段分配到当地日期，分钟余量归最后一个学习日，统计总和保持一致。

今日、本周（周一开始）、本月与连续学习按真实设备日期计算，不依赖临时查看的学期。今日未学习时从昨天计算连续天数；同时显示历史最长。趋势可切换本周/本月，零数据日期仍显示。课程统计使用 courseId，不合并不同学期同名课程；删除后的快照进入其他学习并说明原课程。

## 计时状态机

专注/短休息，默认 25/5；自定义专注 1–180 分钟、休息 1–60 分钟。运行状态依赖 targetEndTime − Date.now()，interval 只刷新显示。暂停保存剩余时间并结束活跃段；继续生成新目标时间。设置和学习内容在周期开始时冻结。

全局恢复机制在路由外工作，刷新/重新打开/visibilitychange 后检查过期周期。完整专注自动保存确定性周期 ID 的记录，并切换到等待启动的休息模式；休息不记录，也不自动循环。提前结束或重置活动周期必须确认，可保存整分钟的有效专注或放弃，不足一分钟明确提示不会保存。暂停期间保持剩余时间。完成提示在页面内，无通知权限。

全部共享快照事务（迁移、学期/课程/任务/考试/学习 CRUD 与计时）用同一个 Web Lock 在同源标签页间串行化，锁内重新读取最新快照并校验周期 ID/快照。快照比较忽略对象键顺序，保留数组与值的变化；发生并发冲突时刷新最新数据并要求重试，避免旧快照覆盖新记录。计时状态与记录同一次提交。存储失败保留原计时状态，展示错误并可重试。异常持久化数据保留原始数据、阻止覆盖并显示恢复提示，避免静默丢失。浏览器不支持 Web Locks 时阻止启动专注并解释限制，手动记录仍可用。

系统时钟回拨时剩余时间上限取已保存的剩余值，恢复时间不早于已保存活跃段结束。暂停超过一年后仍允许恢复，单条实际活跃时长上限保持 24 小时；无活跃段的连续时间记录同时限制真实起止跨度，避免异常大范围日期计算。统计在记录发生变化时使用新鲜的设备时间重新聚合，不等待分钟刷新。

## UI 与关联保护

学习统计页：四张摘要卡、圆形专注计时、本周/本月趋势、课程时长条、历史记录（搜索、范围、课程筛选、分页）、记录 CRUD/详情弹窗。复用现有 Modal、主题 token 和按钮；PC 两列工作区、手机单列、44px 操作、滚动表单与安全底部留白。

删除课程保留所有学习记录、解除课程关联并保留名称快照；删除学期保留记录并解除学期/课程关联，现有考试迁移逻辑不变，确认弹窗列出受影响学习记录。运行中的计时关联同样解除并保留标题/快照。

首页本周学习用真实记录，并作为学习统计入口；快捷访问保持原有四个入口，增加同样风格的学习记录入口，合理换行。
