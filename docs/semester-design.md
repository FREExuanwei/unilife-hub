# 学期与周次升级

保留现有页面结构、网站收藏、主题、导航和课程数据。在设置页及课程表入口提供同一学期表单。课程支持每周、单周、双周及自定义，保存可计算的 weeks 数组和 weekMode。

周一至周日为一周，开始日期所在周为第 1 周，开始日期之前尚未开始。使用本地日历日期计算，避免 UTC 时差和夏令时造成的周次误差。当前日期超出最后一周后不返回越界周次。首页和今日课程始终使用真实周次，指定周浏览不影响今日课程。

课程表默认本周，支持指定周选择/前后切换，以及全部课程管理。只有星期、时间和周次交集同时满足才冲突。缩短学期时列出受影响课程，明确确认后修剪周次；若某门课程没有剩余周次，保留课程及其他信息，标记待重新安排，并在全部课程中可编辑。

继续使用原有 unilife-courses:v1 存储键，升级其内容为 version 2，将学期和课程保存在同一个快照中，实现单次原子写入，避免分开写入导致学期和课程不一致。version 1 只读兼容，在未设置学期时保留旧课程及待迁移标记；首次设置学期时转为整个学期每周上课。读取不写入，失败不覆盖损坏数据，写入失败不改变界面状态。不清空其他 localStorage 数据。

实施顺序：先验证日期/周次/冲突/迁移/缩短学期规则，再实现共享数据与表单，接入课程表和首页，最后进行浏览器交互、两种主题、响应式、收藏回归及生产构建检查。无需新依赖，仅本地开发。
