# 第四阶段设计

在已有 React/TypeScript/CSS 项目中扩展多学期与任务，保留布局、收藏、主题、周次和导航，不增加依赖、不部署。

## 数据与迁移

- Semester 增加稳定 id；Course 使用 semesterId，迁移前未设置学期的旧课程可以暂时为 null。
- 原 unilife-courses:v1 键升级为 version 3 快照：semesters / courses / tasks。任务解析、校验与业务逻辑独立置于 features/tasks；存储统一一次 setItem，保证跨关联操作原子性。
- v2 单学期绑定为固定 legacy-semester id，保留全部课程字段；成功保存 v3 后不再迁移。v1 无学期课程继续等待用户首次设置，不猜测开始日期和周数。
- 无效快照不覆盖；保存失败不更改内存，不关闭输入表单。跨标签页监听同一快照。

## 学期

- 课程表、任务页和设置页共享简单选择器、新建/编辑/删除弹窗，选择保存在页面局部 state，不保存最后查看学期。
- 日期范围保持原有周一到周日规则：开始日期到第 N 周周日。重叠阻止保存并提示。最近学期按距离日期边界，等距优先未来学期。
- 首页始终按真实日期选择；假期不产生今日课程。页面重新进入重新计算默认学期。
- 新学期为空，课程冲突仅在同学期检测；缩短仅修剪该学期周次且需确认，保留课程。
- 删除最后一个学期禁止；其他学期删除弹窗说明课程数和任务数，并要求勾选确认。课程删除保留任务并解除课程关联；学期删除默认将相关任务保留为全局任务，记录原关联说明。

## 任务

- 两类型 assignment/todo；优先级 low/normal/high/urgent；pending/completed 状态及 completedAt。
- assignment 必须有有效学期，课程选填且只能选该学期课程。todo 可选该学期或全局。时间必须配合日期。
- 本地日期和时钟计算：仅日期截止在当日结束，超过截止时间才逾期；无截止不逾期；已完成不逾期。
- 学期筛选包含该学期任务与全部全局任务；搜索标题/描述/课程名，状态和类型可组合。未完成优先，截止时间升序，同截止按优先级，已完成在后。
- 卡片独立详情/完成/编辑/删除入口，删除确认；首页计数、最多三条近期任务以及添加任务跳转联动；课程详情链接筛选相关作业。
- 复用原生 dialog、标签与色彩 token；移动单列、可滚动表单与筛选、44px 操作目标、底部安全留白、减少动效支持。

## 验证

纯逻辑覆盖迁移、范围、独立性、关联保护、截止边界、状态、排序和 schema；浏览器覆盖 CRUD、筛选、日期自动回归、主页、刷新/重新打开、主题、多尺寸和存储异常；最后运行完整测试、TypeScript 与生产构建。未配置 ESLint，不引入额外检查依赖。
