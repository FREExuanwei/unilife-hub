# 第 5 阶段：考试管理

按用户完整需求直接在当前项目实现，保留现有模块、配色和数据；本地开发与测试，完成后停止。使用设计规划、测试驱动与完成验证流程。用户已明确要求直接实施，因此不增加设计审批停顿。当前目录没有 Git 仓库，不创建仓库或工作树。

## 数据与保护

- 考试是独立 Exam 类型，不是 Task；独立 examTypes、examUtils、examStorage、useExams 模块。
- 沿用共享原子快照与旧 storage key，将版本从 3 升为 4，新增 exams。旧版 1/2/3 迁移保留课程、学期、任务全部字段，不新增示例考试。网站收藏存储保持独立。
- 考试必有所属学期，可不关联课程。删除课程只解绑考试并保留来源说明；删除包含考试的学期必须选择另一个有效学期，全部考试迁移并解绑已删除课程。原任务全局化策略保留。一次原子写入避免配额错误时部分删除。
- 编辑、解绑或迁移更新 updatedAt，createdAt 与考试安排保留。
- 损坏快照不覆盖，显示错误并阻止写入。跨标签页同步。用户输入仅 React 纯文本渲染。

## 时间语义

- YYYY-MM-DD 使用已有严格本地日期解析，天数按日历日计算，不按 UTC 字符串解析。
- 日期过去或达到填写的结束时间：已结束。当天达到开始时间且尚未到已填写结束时间：进行中。
- 没有结束时间时保留今天状态直到当天结束，不虚构考试时长；只有结束时间也允许，达到该时间即结束。
- 未来显示还有 N 天 / 明天，当天未开始显示小时分钟或今天考试；不出现负数。分钟定时刷新及恢复页面时刷新。
- 未来升序、历史倒序，默认即将考试；今天与 7 天内只包含未结束考试，7 天内含今天至第 7 天。
- 日期不在学期范围时清晰警告并显式勾选仍保存，不硬性禁止；改动所属学期或日期后重新确认。

## 页面与联动

- 页面沿用学期选择器；三项统计、下一场考试、搜索、状态与类型筛选、卡片列表、空状态。
- 表单、详情、删除确认复用可滚动且锁焦点的 Modal；课程下拉只取表单所属学期。
- 首页只读取真实日期对应学期（日期空档不冒充真实当前学期），显示最近未结束考试与三天内强调。课程详情提供最近关联考试及详情链接。
- 手机单列、44px 触摸控件、筛选局部滚动、输入不溢出、底部安全间距；浅深色复用蓝紫/橙/受控红/灰蓝 tokens。
