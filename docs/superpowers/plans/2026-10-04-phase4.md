# UniLife Hub 第四阶段 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 逐项执行；按用户要求直接在当前工作区实现。

**Goal:** 多学期独立课程与可靠的作业/待办管理。

**Architecture:** 在已有课程快照上升级 v3，独立任务解析和逻辑模块，集中事务保存；所有页面选择为临时状态。

**Tech Stack:** 现有 React / Vite / TypeScript / CSS / Lucide / React Router，不增加依赖。

**Spec:** docs/phase4-design.md

## Global Constraints

仅本地开发测试。保留既有功能和旧数据，不开发第五阶段。输入为纯文本，坏存储阻止覆盖。

## Review Focus

1. 旧数据迁移失败保持原值和输入。
2. 时间跨午夜、学期间隔、非周一开学准确。
3. 课程和学期删除保护任务，存储失败整体不变。
4. 临时历史学期不污染首页或重进默认。
5. 窄屏长标题、弹窗焦点、底部导航安全留白。
