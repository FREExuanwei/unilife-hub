# Phase 6 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task; one fresh reviewer at completion.

**Goal:** Complete learning records, real-date statistics and persistent accurate focus timer without breaking prior features.

**Architecture:** Independent study/pomodoro modules share an atomic version-5 snapshot with existing course data. Pure state transitions feed the existing provider, with a common Web Lock for all shared writes. Components consume typed hooks and memoized aggregation.

**Tech Stack:** Existing React, TypeScript, Vite, CSS, Lucide; no new dependencies.

**Spec:** ../../phase6-design.md

## Global constraints

- Local development/testing only. No deployment, login, cloud, import/export, PWA, notifications or phase 7.
- Preserve original storage keys and all v1–4 records and metadata.
- Device local time; Monday starts weeks; integer minutes; 1–1440 per record.
- Persist timer/record together and never overwrite malformed storage.
- User supplied complete implementation authorization; no repeated design approval. No Git repository, so work in the authorized existing directory without commits/worktree scripts.

## Review focus

- Concurrent restored tabs: one completed focus produces exactly one record.
- Paused timer across midnight: pause time excluded and daily allocation sums exactly to duration.
- Timer/course deletion races: no invalid associations or destroyed historical records.
- Quota/malformed storage: no falsely saved UI or lost previous snapshot.
- Long text / narrow screen / modal keyboard access: no overflow or hidden controls.
